Personal project · full-stack2026

Portfolio Tracker DAILY USE

Tracks a stock & crypto portfolio across three brokers — live Trading 212 API sync plus XTB (.xlsx) and Revolut (.pdf) statement import — and calculates returns in USD/CZK, dividend income and risk metrics, and generates a Czech tax report.

  • PostgreSQL with row-level security; triggers keep positions and cash consistent with the transaction ledger.
  • 11 serverless functions + scheduled jobs (pg_cron, GitHub Actions): price refresh with a provider fallback chain and a shared cache, so each ticker is fetched once for all users.
  • Resumable broker sync with a cursor to stay within execution time limits and respect API rate limits; statement import with duplicate detection, so re-uploading a file doesn't count trades twice.
  • FIFO cost basis per broker account with historical FX rates, the Czech 3-year tax-exemption test per lot, Sharpe ratio and max drawdown.
  • Broker API keys encrypted at rest (pgcrypto + Vault). ~230 unit tests (Vitest).
